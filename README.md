# HD Investments - Stock Trading Platform

A modern stock trading and portfolio management application built with Next.js.

## Features

- User authentication (login/signup)
- Portfolio management and creation
- Real-time stock data viewing
- Buy and sell stocks
- Transaction history tracking
- Friends system for social trading
- Stock lists for organizing favorites
- Daily stock updates
- Predictive analysis for stock performance

## Tech Stack

- **Frontend**: Next.js, React
- **Styling**: CSS-in-JS with inline styles
- **Database**: PostgreSQL
- **Charts**: Chart.js with react-chartjs-2

## Getting Started

1. Install dependencies:

```bash
cd my-nextjs-app
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `/pages` - Next.js pages and API routes
- `/pages/api` - Backend API endpoints
- `/styles` - Global CSS styles
- `/public` - Static assets (images, logos)

## API Endpoints

- `/api/login` - User authentication
- `/api/signup` - User registration
- `/api/stocks` - Stock data
- `/api/portfolios` - Portfolio management
- `/api/transactions` - Transaction history
- `/api/friends` - Social features
